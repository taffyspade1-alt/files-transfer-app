# 文件传输应用 · 局域网手机 ⇄ Windows 互传

一个跑在 Windows 电脑上的小型文件互传工具。手机和电脑连同一个 WiFi，用浏览器就能双向传文件：**不装 App、不注册账号、不经过公网、不需要外部服务器**。

- 手机 → 电脑：手机选文件 / 拍照上传，电脑网页里预览或下载
- 电脑 → 手机：电脑网页上传，手机「接收文件」标签里下载或预览
- 图片、视频、音频、PDF、文本支持在网页内直接打开

---

## 一、启动

**双击 `start.bat`**。

- 首次运行会自动执行 `npm install`（只需联网一次），之后不再需要
- 启动后自动打开电脑端页面 `http://127.0.0.1:8787`
- **黑色命令行窗口要保持打开**，关闭窗口 = 停止服务
- 首次启动若弹出 Windows 防火墙提示，勾选「专用网络」并允许

启动成功后窗口会显示：

```text
电脑打开 : http://127.0.0.1:8787
手机打开 : http://192.168.x.x:8787/upload
房间码   : home    口令: 123456
```

> 需要 Node.js 22 或更高版本（用到内置 `node:sqlite`）。`node` 必须能在 PATH 中找到，找不到时启动脚本会给出明确提示。

## 二、手机连接

1. 手机与电脑连接**同一个 WiFi**
2. 电脑端页面输入房间码与口令：
   - 房间码：`home`（已自动填好）
   - 口令：`123456`
3. 手机扫描电脑页面上的二维码（或在手机浏览器手动输入页面上的「手机访问」地址）
4. 手机端同样输入房间码与口令（房间码自动填好，只需输口令）→ 进入

登录状态默认保留 7 天（`.env` 的 `SESSION_HOURS`），期间不用重复输入。

**手机打不开时按序排查**

| 现象 | 处理 |
| --- | --- |
| 一直转圈 / 连不上 | 防火墙弹窗勾选「专用网络」，放行 `node.exe` |
| 同一 WiFi 仍打不开 | 校园网 / 公司网 / 访客 WiFi 常开启「AP 隔离」，禁止设备互访 → 让电脑开「移动热点」，手机连电脑的热点 |
| 二维码地址不对 | 多网卡或 VMware / VirtualBox 虚拟网卡会选错 IP，在电脑端「本机网卡」下拉框切换 |
| 提示端口被占用 | 已有一个实例在运行，直接打开 `http://127.0.0.1:8787`；或改 `.env` 的 `PORT` |
| 双击 `start.bat` 闪退 | 在文件夹地址栏输入 `cmd` 回车，手动敲 `start.bat`，窗口会保留报错信息 |

## 三、双向传输

### 手机 → 电脑

手机端「**发送文件**」标签 → 点选文件 / 拍照 / 拖拽 → 「开始上传」→ 电脑端列表自动出现 → 点「预览」在网页内打开，或「下载」保存到电脑。

### 电脑 → 手机

1. 电脑端点工具栏蓝色「**发送文件到手机**」→ 选文件 → 开始上传
2. 手机切到顶部「**接收文件**」标签，文件自动出现（有红点提示）
3. 点「下载」存到手机，或「预览」在浏览器打开

> 两端共用一个文件池：任一端上传的文件，两端列表都能看到、都能下载。手机下载一般进系统「下载」目录；iOS Safari 通常保存到「文件」App。

其它操作：列表支持搜索与刷新；电脑端可删除文件（同时删除磁盘本体）；电脑端右上角「退出房间」可切换登录。

## 四、在线预览支持

| 类型 | 网页内打开 | 说明 |
| --- | --- | --- |
| 图片 jpg / png / gif / webp / bmp / heic | ✅ | 直接显示 |
| 视频 mp4 / mkv / mov / avi / webm | ✅ | 可拖进度条（服务端支持 Range 206） |
| 音频 mp3 / m4a / flac / wav / ogg | ✅ | 直接播放 |
| PDF | ✅ | 浏览器自带查看器 |
| 文本 / 代码 / CSV / 日志 | ✅ | 电脑端 ≤2MB 页内渲染；手机端新标签打开 |
| Word / Excel / PPT / 压缩包 | ❌ | 下载后用本地软件打开 |
| HTML / SVG / JS | ❌ | 强制下载，防止上传的脚本在网页内执行 |

## 五、配置项

全部在 `.env`，**改完需重启服务**（关掉黑窗口再双击 `start.bat`）。

| 项 | 当前值 | 说明 |
| --- | --- | --- |
| `PORT` | `8787` | 服务端口，手机和电脑都访问它 |
| `HOST` | `0.0.0.0` | 允许局域网访问，**不要改成 `127.0.0.1`** |
| `ROOM_CODE` | `home` | 房间码，两端必须一致 |
| `ROOM_PIN` | `123456` | 房间口令，两端必须一致；建议改成自己的 |
| `MAX_FILE_MB` | `2048` | 单文件上限（MB），`0` 表示不限 |
| `RETAIN_DAYS` | `0` | 文件保留天数，`0` 表示永久；服务每小时清理一次过期文件 |
| `SESSION_HOURS` | `168` | 登录有效小时数（默认 7 天） |
| `AUTO_OPEN` | `0` | 是否自动打开浏览器；`start.bat` 会临时覆盖为 `1` |
| `SESSION_SECRET` | 未设置 | 会话签名密钥；不填则自动生成并保存在 `data/session.key` |

## 六、目录结构

```text
文件传输应用/
├── start.bat              # 双击启动（自动装依赖 / 自动开页面）
├── server.js              # HTTP 服务、API、房间鉴权、预览/下载/Range、SSE
├── config.js              # 读取 .env
├── db.js                  # SQLite 数据层（参数化查询）
├── .env                   # 配置
├── package.json
├── public/                # 前端，原生 HTML/CSS/JS，无构建步骤
│   ├── index.html         # 电脑端：列表 / 预览 / 下载 / 二维码
│   ├── upload.html        # 手机与电脑共用：发送文件 / 接收文件 双标签
│   ├── app.js             # 电脑端逻辑
│   ├── upload.js          # 上传（进度条、多文件、拍照、拖拽）
│   ├── receive.js         # 接收页逻辑
│   ├── common.js          # 登录、请求封装、工具函数
│   └── style.css
├── storage/               # 文件本体（UUID 命名，与真实文件名解耦）
└── data/
    ├── files.db           # SQLite：文件名、大小、类型、磁盘名、时间
    └── session.key        # 自动生成的会话签名密钥
```

数据库只存元数据，文件本体落磁盘，两者用 `disk_name` 关联；这样大文件传输、视频拖动进度条都稳定。

## 七、安全与限制

- 房间码 + 口令在**服务端**校验，登录后下发 HMAC 签名 Cookie（HttpOnly / SameSite=Lax）；未登录访问任何文件接口都返回 401
- 文件名消毒、磁盘路径白名单、SQL 全参数化；HTML / SVG / JS 强制 `attachment`，防止脚本注入
- 局域网内 HTTP **明文传输**，仅限可信内网使用，不要暴露到公网
- 必须电脑开机且服务运行、两端同一网络；**不支持异地 / 公网传输**
- 单次最多 20 个文件；单文件上限由 `MAX_FILE_MB` 控制
- 二维码指向「发送文件」页，手机需要手动点一次「接收文件」标签

## 八、技术栈与手动启动

Node.js 22+ · Express 4 · multer 2（流式落盘）· qrcode · 内置 `node:sqlite`（WAL 模式）· 原生前端 + SSE 实时推送。

不想用 `start.bat` 时：

```bash
npm install
npm start
```

然后手动打开 `http://127.0.0.1:8787`。

### 主要接口

| 方法 | 路径 | 作用 |
| --- | --- | --- |
| `POST` | `/api/login` | 房间码 + 口令登录 |
| `POST` | `/api/logout` | 退出房间 |
| `GET` | `/api/config` | 房间码、二维码、局域网地址、网卡候选 |
| `GET` | `/api/files` | 文件列表（支持 `q` / `limit` / `offset`） |
| `POST` | `/api/files` | multipart 上传（最多 20 个） |
| `GET` | `/api/files/:id` | 在线预览（`inline`，支持 Range 206） |
| `GET` | `/api/files/:id?dl=1` | 下载（`attachment`，保留原文件名） |
| `DELETE` | `/api/files/:id` | 删除记录与磁盘文件 |
| `GET` | `/api/events` | SSE，新文件 / 删除实时通知 |
